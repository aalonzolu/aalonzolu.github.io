# aalonzolu.github.io

Sitio personal de Andrés Alonzo — https://aalonzolu.github.io

HTML y CSS a mano, sin dependencias ni build. Para editarlo, `index.html` y `style.css`.

## Qué NO va aquí
Decisión del 2026-10-13, por spam y por riesgo de ataques dirigidos:
- **Sin correo ni teléfono.** El contacto va por LinkedIn.
- **Sin CV en PDF.** El PDF trae el teléfono; se manda a quien lo pida.
- **Sin historial laboral** con nombres de empresas ni fechas. Eso es material de CV, no de portafolio.
- **Sin ciudad exacta** ni datos de estudios.
- La página lleva `noindex, nofollow, noarchive`: funciona si alguien tiene el enlace, pero no
  la indexan los buscadores ni la archivan.
